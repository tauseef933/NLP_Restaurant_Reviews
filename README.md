#🍽️ Restaurant Reviews Sentiment Analysis (NLP)
Predict customer sentiment (positive/negative) from restaurant reviews using Natural Language Processing techniques.

🔍 Key Features
NLP pipeline with text preprocessing (tokenization, stemming/lemmatization, stopword removal)

Model comparisons: Naive Bayes, Logistic Regression, LSTM

TF-IDF & Word Embeddings for text vectorization

Accuracy: 80-90% (depending on model)

Interactive demo to test custom reviews

🛠️ Tech Stack
Python · NLTK · spaCy · Scikit-learn · TensorFlow/Keras

Jupyter Notebook · Pandas · Matplotlib
